# Отчет о доработках (Backend)

Я провел анализ проекта и "довел до ума" недостающие интеграции.

## 1. ✅ Интеграция Адресов (Addresses)
Ранее приложение имело функционал сохранения адресов, но при оформлении заказа их нельзя было использовать (нужно было вводить заново).
**Сделано:**
- Обновлен `CartView.patch` (`/api/orders/cart/`): теперь принимает `address_id`.
- Обновлен `CheckoutView.post` (`/api/orders/checkout/`): теперь принимает `address_id`.

**Как использовать (Frontend):**
При отправке запроса на оформление заказа или обновление корзины, достаточно передать ID адреса:
```json
{
  "delivery_type": "delivery",
  "address_id": 5  // ID выбранного адреса
}
```
Бэкенд автоматически подтянет:
- Текст адреса (`address_text`)
- Координаты (`latitude`, `longitude`)

## 2. ✅ Избранное (Favorites)
Модуль был реализован, но не проверен. API полностью готово к использованию:
- `POST /api/favorites/toggle/` - добавить/удалить
- `GET /api/favorites/` - получить список

## 3. ✅ Промокоды и Скидки
Логика полностью реализована на бэкенде:
- `POST /api/orders/validate-promo/` - проверка кода
- `POST /api/orders/apply-promo/` - применение к корзине

## 4. ✅ Отмена заказов (Cancellation)
Реализована сложная логика отмены с подтверждением оператора:
- Пользватель создает запрос: `POST /api/orders/cancel_order/`
- Оператор видит запрос в Админке (`OrderCancellationRequest`)
- Оператор одобряет/отклоняет -> статус заказа меняется.

## 5. ✅ Оплата (Click)
Ранее исправлено и протестировано (Mock режим работает).


## 6. ✅ Уведомления (Notifications)
Реализована система автоматических уведомлений через Telegram бота:
- При смене статуса заказа (`preparing`, `delivering`, `done`, `canceled`) пользователю автоматически отправляется сообщение в бот.
- Используются Django Signals (`orders/signals.py`).

## 7. ✅ Время работы (Operating Hours)
Добавлена проверка времени работы ресторана:
- Функция `is_restaurant_open()` в `orders/utils.py`.
- Блокировка оформления заказа (`CheckoutView`) в нерабочее время (сейчас настроено 10:00 - 23:00).
