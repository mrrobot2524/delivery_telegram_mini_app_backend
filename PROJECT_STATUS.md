## ❌ Что НЕ работает (критично!)

### 1. Акции (Promotions) не применяются к ценам

**Проблема:**
- Акции создаются в админке ✅
- Фронтенд показывает акции ✅
- **НО:** При добавлении товара в корзину цена берется БЕЗ скидки ❌

**Пример:**
- Товар: 50,000 сум
- Акция: -20%
- Ожидаемая цена в корзине: 40,000 сум
- **Реальная цена в корзине: 50,000 сум** ❌

**Решение:**
📄 Смотрите файл `FIX_PROMOTIONS_GUIDE.md` для пошаговой инструкции

**Краткое решение:**
1. Добавить метод `get_discounted_price()` в модель `Product`
2. Изменить логику добавления в корзину (использовать `product.get_discounted_price()`)
3. Обновить сериализатор для отображения скидки в API

## 📞 Контакты и поддержка

**Проект:** KY Sushi - Telegram Mini App для заказа суши

**Технологии:**
- Backend: Django 5.0 + Django REST Framework
- Frontend: React + Vite
- Database: PostgreSQL
- Queue: Celery + File System Broker
- Payment: Click Payment Gateway
- Maps: Leaflet + OpenStreetMap

**Структура проекта:**
```
ky_sushi/              # Django Backend
├── core/              # Настройки проекта
├── orders/            # Заказы, корзина, оплата
├── menu/              # Товары и категории
├── telegram_users/    # Пользователи Telegram
├── addresses/         # Адреса доставки
└── content/           # Контент (акции, вакансии, филиалы)

ky_sushi_front/        # React Frontend
├── src/
│   ├── components/    # Компоненты UI
│   ├── pages/         # Страницы
│   └── api/           # API клиент
```
