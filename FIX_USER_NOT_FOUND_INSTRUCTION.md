# 🛠 Как исправить "Telegram user not found"

**Дата:** 2025-12-08  
**Время:** 21:00

Если вы видите ошибку **"User not found"** или **"Telegram user not found"** при открытии приложения, значит сервер еще не обновил логику регистрации.

Мы уже внесли необходимые изменения в код (`src/telegram_users/views.py`), добавив автоматическое создание пользователя при входе. Но эти изменения вступят в силу только после перезапуска сервера.

### 📋 Что нужно сделать:

1.  **Остановите сервер Django** (в терминале, где запущен `python manage.py runserver`), нажав `Ctrl+C`.
2.  **Запустите сервер снова**:
    ```bash
    python manage.py runserver
    ```
3.  **Перезапустите бота** (если еще не делали):
    ```bash
    python manage.py runbot
    ```

### ✅ Результат:

- После перезапуска сервера, когда вы откроете приложение (через новую кнопку "🍣 Оформить заказ" или кнопку "📱 Открыть приложение"), сервер **автоматически создаст** ваш профиль.
- Ошибка исчезнет, и вы увидите меню.
